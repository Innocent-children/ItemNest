# ItemTrace 第一阶段源码分层

- `common`：领域错误、结果类型和输入校验。
- `model`：物品、分类、位置、查询和派生状态模型。
- `data/rdb`：RDB Store 打开、事务、版本和表结构。
- `data/dao`：仅负责参数化持久化与行映射。
- `data/repository`：向服务层提供领域数据访问契约。
- `service`：创建、编辑、查询、状态计算与首页摘要等用例。
- `navigation`：页面路由名、参数与返回结果约定。
- `components`：不访问数据库的可复用 ArkUI 组件。

页面层只能调用服务层；DAO 与 RDB 行不得直接泄漏到页面。图片、提醒、扫码和服务卡片属于后续阶段，
第一阶段不得在上述目录中调用其系统能力。
