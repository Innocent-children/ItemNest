# 导入导出契约：ItemTrace Phase 3 本地 JSON

本契约只定义本地导入导出的数据格式与预检规则，不定义云同步、账号、多人共享或外部分享。
导出的 JSON 可由用户自行保存或备份；应用不得把文件上传到服务端。

## 格式

根对象：

- `version`: 固定为 `itemtrace.phase3.v1`
- `exportedAt`: 导出时的毫秒时间戳
- `items`: Item 数组
- `batches`: Batch 数组
- `locations`: Location 数组
- `categories`: Category 数组
- `traceEvents`: TraceEvent 数组

## 隐私边界

- 不包含账号、云端地址、设备标识、系统权限状态、原始错误堆栈或敏感日志。
- 图片二进制不进入导出文件；如需导出图片文件，必须另立规格定义用户确认、文件复制和失败回退。
- 导入前必须完成 JSON 结构和版本预检；预检失败不得写入 RDB。

## 冲突与确认

- 当前实现提供本地 JSON 导出和导入预检/确认结果，不自动覆盖现有数据库。
- 后续如需真正合并写入，必须补充冲突策略：同 ID 覆盖、重命名、跳过、合并事件，以及失败回滚样本。
- 用户未确认时不得执行导入确认流程。

## 降级

系统分享或文件选择能力未在本契约中启用。能力不可用时，主应用内的 Item、Batch、位置、分类和借还记录仍可正常使用。
