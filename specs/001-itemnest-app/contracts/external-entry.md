# Contract: 链接、系统入口、卡片与 AI

## 路由输入

| 输入 | 白名单格式 | 行为 |
| --- | --- | --- |
| 物品 | `itemnest://item/{itemId}` | 打开有效物品；不存在或已删除则提示并停在物品栏目 |
| 位置标签 | `itemnest://location/{token}` | 只按本机 token 映射打开位置；失效提供绑定到位置 |
| 功能 | `itemnest://function/{action}` | action 为 add、scan、camera、voice、search、todo、expiry、loans、shopping、backup、system |
| 分享 | 一张图片或一段纯文本 | 保存旧草稿，再打开预填记下面板 |
| NFC | 白名单 NDEF URI | 与链接相同；写入覆盖前确认，不自动执行写命令 |
| 通知 | 本应用构造的物品/待办目标 | 打开页面；任何修改仍需确认 |

总长不超过 4096 字符，ID/token 不超过 200 字符且无控制字符；严格校验 scheme、host、路径层数、编码和 action，不执行未知参数。图片 URI 只按系统授予的可读范围导入，不能将 URI 当任意本地路径。token 不携带物品内容，不是跨设备共享数据库的凭证。

`EntryRouter.resolve(request)` 输出只读目标或待确认的 `CaptureCandidate` / `CommandCandidate`。包含来源、原始文字、解析字段、歧义候选和匹配目标；重新读取目标后用户确认才执行。多个同名物品或位置不能取第一条直接写入。

## 独立核验的端 A2A 智能体

SYS-06 原 P1 保留追溯并纳入当前非企业范围，由工程师主动核对接入方式、真实平台条件及设备支持。无法开通时隐藏不可操作入口、记录具体平台阻塞并保留本地查询，不按优先级自行延期，也不把隐藏入口当作接入完成。平台问题只影响该适配器，不阻塞工程与独立功能。

接入后只允许查询、生成待确认改动和待办摘要；不暴露任意 SQL、文件读取或直接库存写入。关闭小艺访问后先拒绝读库；修改候选进入统一面板确认，不依赖企业意图或 localChatModel。

## AI 候选与问答

- OCR、条码和语音输出候选，不覆盖用户已输入内容；生产日期不能充当到期日，推算到期明确标注依据。
- 拍多件识别结果需逐件确认名称和位置。歧义日期、人名、数量和单位保留识别到的原始文字供核对。
- 查询先产生事实列表，包括 itemId、在手/共有、单位、位置、日期和借还。核心直接展示查询结果卡片和依据，不导入 localChatModel，不显示模型准备或生成进度；生成部分留文末可选扩展。
- 所有能力遵循 `capability-compatibility.md` 分别检测接口版本、SysCap、专用支持、资源、权限与偏好。永久不支持时隐藏增强入口，可恢复状态提供适当说明与手工替代；保留照片、原文和草稿，返回应用或再次使用时重新检测，不把权限拒绝或初始化失败永久判为设备不支持。
- 由 OCR、文本分析、语音等服务产生的候选均可缺省，不能阻塞手工记下或普通查询。高版本组件创建与适配器初始化也要保护，不只保护最终业务调用；禁止依靠芯片档次或仅有编译声明推定可用。

## 服务卡片

W1/W2/W3 为P0；W4/W5/W6 为P1，尺寸按需求表定义。W4–W6 编辑配置只保存有效目标 ID；目标删除后显示可重选状态。

W6 ConsumeOne 要包含 cardInstanceId、itemId、operationId 和显示数据版本，在事务中读取最新数量。每次真实点击一个新 operationId，系统重复投递保留同 ID。只允许当前用户配置到该卡片的消耗品，不能通过任意外部参数触发该例外。结果显示五秒撤销；旧回执不覆盖后续操作。

卡片快照包含源数据版本、计算日期和有效项目。写入后主动刷新，每日 00:01 为期望定点刷新（`updateDuration: 0`），受系统调度限制；重新可见/应用启动时对账。缓存过时不编造数量，不在 UI 展示内部数据版本。`setFormNextRefreshTime` 不得设置小于平台最短间隔。

## 分享

文字/图片先预览。碰一碰也必须遵守预览里选择的字段；尚未设置分享选项时，先到预览，不能从物品页把未确认的隐私字段直接发送。

## 最后：企业受限能力契约（US10，可选，默认不执行）

用户后续选做对应能力且满足主体、设备和范围条件后，本节才成为该扩展的实现要求。未选扩展不共享、不读取、不声明空组件、不暴露可启用入口；核心写入、查询、备份和卡片不等待相关适配器。按 QV-10 独立验收，未选记“可选未实施”，不阻塞核心版本。

### 小艺意图、系统搜索与共享

定义 I1 JumpFunctionPage、I2 ViewSearchPageLocal、I3 QueryStoredItems、I4 RecordStoredItem、I5 ViewStoredItem、I6 ShowTodoCard、E1 itemnest_item。参数集合按 `docs/harmonyos.md` 定义；I3 最多返回 10 条，修改类回答“已准备好，请在应用里确认”。

Intents Kit 企业主体和平台申请由 T148/T150 核验。关闭小艺访问后先拒绝读库；系统搜索单独检查开关，关闭位置显示时实体不带位置。关闭意图共享后清理全部已共享意图，软删除物品后删除相应实体。不将企业意图当作端 A2A 的前置条件。

### 模型生成式问答

localChatModel 当前仅企业可申请、仅 PC/2in1，并要求 INTERNET 权限；当前手机/平板与无网络权限范围不能直接接入。选做时若需扩设备或网络范围，须有新的用户指令，不以云模型或服务端替代。模型只组织 QueryService 查询事实，不计算库存，不执行备注中的指令；流式效果 M24 和生成流光只在选做后接入。

数量、位置、日期与依据不一致时丢弃生成句，使用确定性查询结果。模型不可用、离线模型未就绪或隐私开关关闭时不调用云端替代。

### LV1–LV3 实况窗

整项按用户决定后置为可选；推送路径明确需企业账号，个人本地路径正式商用资格尚未核实。选做后核对正式权益和场景，不以“本地调用”跳过资格核验，不为此新增远程 Push 服务端。LV1 展示备份恢复进度、LV2 展示连续记下件数、LV3 展示购物清单和进度；分别消费既有业务状态，核心不反向依赖。

LV1、LV2、LV3 各自检查用户开关、运行能力和平台权益。LV2/LV3 场景准入先验证；生命周期显式用 API 26 的随进程终止自动结束模式。进程回收后不承诺继续更新；购物会话和录入草稿可在下次应用启动恢复。超过四小时关闭购物实况窗是生命周期规则，不依赖应用自建常驻定时器。
