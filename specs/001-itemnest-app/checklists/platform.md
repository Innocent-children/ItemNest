# Checklist: HarmonyOS 工程与系统能力要求质量

- [ ] CHK001 是否已明确新工程所需的根构建、entry、入口、路由、资源、锁文件和测试入口？[plan.md / platform-readiness.md]
- [ ] CHK002 是否明确公共 build-profile 配置与本机签名的边界，并覆盖项目忽略规则的影响？[T002 / FR-015]

- [ ] CHK010 是否明确本地数据原则用于保护用户数据，华为官方系统能力正常接入，产品隐私开关与外部修改确认按需求实现？[OQ-01]
