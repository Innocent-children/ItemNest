# Quickstart: 后续实施与验收指南

当前没有应用工程，本次未执行下面的应用构建、安装或场景测试。此文说明获得开发指令并完成工程创建后怎样验证；现阶段只运行本文的 SpecKit 文档检查。

## 前置条件与工程建立

1. 阅读项目根 `AGENTS.md`、宪章、本目录的 spec/plan/open-questions；禁止查看受限 Git 历史。
2. 核对 OQ-03 环境资料；从 T001 开始按同版官方 Stage 模板创建新工程。官方系统能力按所选范围正常接入，提醒采用一次提醒、同日合并。US10 / T148–T154 企业扩展默认不执行，不提前准备申请材料，不阻塞核心工程与发布。
3. 锁定 DevEco、API 26 SDK、Hvigor 和依赖锁文件；记录工具输出。签名在本机配置，不把证书或口令放入公共构建文件。
4. 完成公共构建配置、entry、入口、路由和最小资源后，在 DevEco 执行同步、静态检查和构建 HAP。工程没有这些文件之前不要求运行构建。

## 构建与设备测试入口（未来执行）

若所选官方模板提供 `hvigorw`，先用 `./hvigorw --help` 和任务列表核对；不提供 wrapper 时按已锁定 DevEco 的 Hvigor 启动方式执行，不能下载未知脚本代替。

模板确实定义 product=default、module=entry@default、assembleHap 时，构建入口为：

```sh
./hvigorw --mode module -p product=default -p module=entry@default -p buildMode=debug assembleHap
```

测试使用 DevEco 的本地单元测试运行入口和 `entry/src/ohosTest` 的设备测试入口；T008 必须把所选版本实际可用的测试任务、命令和输出路径记录到工程说明。不同版本未核定前不伪造 `test` 命令。设备安装用 DevEco 的 Run/Debug，或在 `hdc list targets` 确认设备后对构建产物执行 `hdc install <实际产物绝对路径>`；此处参数说明不是当前可执行的文件路径。

每次记录：工具版本、设备型号/系统、签名类型、实际命令或操作、结果、截图/日志位置；失败不能勾选需求通过。
