# 我的家当：交互原型说明

版本：1.1 · 2026-11-01。原型用于体验页面关系、记录负担、内容层级、组件反馈和代表性动效，与产品文档共用 P01—P23 编号。

## 1. 打开方式

在浏览器打开本目录的 [index.html](index.html)。入口、样式、交互和图片均随目录保存，浏览器直接加载即可。通过本地静态服务打开时，服务根目录选择 `Docs/Prototype/`。本轮查看地址为 `http://127.0.0.1:4173/`，服务运行期间可用。

手机查看可使用本机 HDC 将手机的 4173 端口映射到本地 4173 端口，再在手机浏览器打开上述地址。本轮已按该方式在用户连接手机上查看。后续使用时按当时的设备连接标识建立端口映射。

- 桌面：左侧为体验路径，中央为手机画面，右侧为核心设计说明。
- 手机：保留原型工具栏与可触控的完整页面，内容随可用高度滚动。
- 顶部“空白开始 / 查看示例”：切换自己的演示记录与示例家当，两份内容分别保存。
- 顶部“场景”：进入主要页面，以及加载、读取提示等审阅场景。
- 画面下方：显示当前 P 编号，便于与页面规格核对。

原型首次打开展示八条虚构物品记录，包含化妆品直接日期与电池保质期两种示例。已有浏览器演示记录继续保留；本轮新增两条日期示例。界面中的物品图为随原型保存的 SVG 插图，品牌人物图来自项目已有图标。浏览器使用 `localStorage` 保存本次演示内容，键为 `itemnest-product-prototype-1`；不同浏览器各自保存。演示时选择的图片保存在该浏览器的本地原型数据中，容量按浏览器实际可用空间决定。

## 2. 建议体验的任务路径

| 路径 | 实际操作 | 重点观察 |
| --- | --- |
| 从一件开始 | 空白开始 → 记下一件 → 填名称 → 保存 → 试着找一下 | 最少输入与第一次可感知的收益 |
| 连续整理 | 查看示例 → 位置 → 书房 → 在这里记下 → 示例图片 → 保存 → 继续记下 | 位置保持可见；下一条照片、名称与数量各自初始化 |
| 找到并更新 | 家当 → 搜索充电器 → 详情 → 找到了 → 改位置 → 玄关 | 查询、确认和维护怎样相连 |
| 整组记录 | 记下 → 记一组 → 填名称与内容说明 → 保存 → 搜索说明中的词 | 用户按自己的整理粒度记录，说明成为寻找线索 |
| 长期使用 | 我的 → 草稿 / 提醒 / 数据管理 / 外观与隐私 | 已有投入怎样继续、怎样带走、怎样随个人设置呈现 |
| 记下到期日期 | 场景 → P20 → 直接填日期，或填生产日期与保质期 → 保存 | 输入时看到计算结果；日期随物品一起保存 |
| 到期后处理 | 场景 → 系统通知示意 → 点击通知 → 提醒列表 → 查看物品 | 一条汇总提醒怎样帮助找到待处理的物品 |
| 再记同款 | 场景 → P22 → 模拟扫描 → 再记同款 | 复用名称和条码，新记录填写自己的数量、位置与日期 |
| 口述填写 | 记录或搜索 → 语音入口 → 查看候选 → 采用文字 | 候选先确认，再进入当前字段 |

“示例图片”提供预置图便于审阅；“拍照”和“从相册选”调用浏览器的文件输入能力，实际界面由浏览器与系统决定。正式应用的 CameraPicker、PhotoViewPicker 接入规则见 [08](../08-HarmonyOS7能力与接入要求.md)。

| P09 位置表单 | 新建、改名、父位置选择、层级与同名提示 |
| P10 批量整理 | 显式选择、全选、批量移位、回收确认与列表更新 |

| P13 数据管理 | 完整备份、CSV 与恢复的预览、选择方式和结果场景 |
| P14 历史 | 归档 / 回收站列表、详情、恢复与影响确认 |
| P15 外观与隐私 | 浅色、深色、跟随系统、简洁动效、卡片摘要开关 |
| P16 接收图片 | 两张示例图，选择每张一件或整组、统一位置并保存 |
| P17 图片与候选 | 主图查看、固定文字候选、将候选填入字段 |
| P18 卡片 | 2×2、2×4、日期摘要及四个图标快捷方式的版式与点击路由 |
| P19 帮助 | 核心记录方式、长期保存及版本说明 |
| P20 到期日期输入区 | 内嵌在录入、编辑的更多信息中，直接日期或生产日期加保质期计算 |

| P23 语音填写 | 固定可编辑候选、重新查看、取消与采纳回原字段 |

正式页面的完整定义由 [05](../05-页面与交互规格.md) 维护。原型的位置选择以完整路径列表表达；原生页面按规格实现搜索、最近位置与面包屑。图片页以单图查看表达层级，原生页面完成多图切换、缩放与主图排序。日期表单以单个日期演示，两种到期填法均可交互；正式数据分别维护到期、保修和归还三类日期。日期列表采用连续卡片表达，正式分组按 P12 实现。日期摘要卡片展示版式，正式摘要开关与更新时间按 P15、P18 实现。

数量拆分、位置迁移、编辑修订冲突、导入资源校验和完整搜索排序按 [09](../09-数据模型与业务规则.md)、[10](../10-隐私权限与数据管理.md) 开发。原型的数据结构服务于交互演示；条码在网页中使用单个码值字段，正式应用保存类型和码值。正式应用使用上述实体与业务规则。
