# 开发实施与交付计划

版本：1.1 · 2026-11-01。本文将产品设计转换为实施顺序。当前交付阶段为产品文档与原型；用户开启应用开发后，按以下阶段实施。

## 1. 先让一条记录产生价值

第一条纵向链路是“打开 → 记下一件 → 看见位置 → 搜索找到 → 改位置”。每个阶段都形成可以在手机上体验的结果，再加入批量整理、系统快捷入口和长期保存能力。本版包含 `03` 中 P0、P1 的需求，优先级决定顺序。受控代理提醒在个人权益具备后接入，系统日历完成个人版可交付的系统提醒路径。F09 的日期输入与计算随 W04 完成，系统承接随 W17 完成。

| 阶段 | 用户得到的完整体验 | 工作项 | 阶段交付与验收 |
| --- | --- | --- | --- |
| D1 能记住一件 | 空首页开始，名称或照片保存，详情可查看 | W01—W04 | 真机可用的记录闭环；A01—A03、A16 |
| D2 能找到和维护 | 位置层级、搜索、整组、连续整理、数量与状态 | W05—W09 | 找到物品并顺手更新；A04、A05、A07—A09、A18、A23 |
| D3 值得长期使用 | 草稿、回收、备份、恢复、主题与帮助 | W10—W13 | 输入可继续，数据可带走；A12、A13、A20、A22、A24 |
| D4 系统随手可达 | 照片文字、桌面卡片、分享收图、到期提醒、扫码、语音和系统换机 | W14—W18、W21—W24 | 系统能力逐项可用并有替代操作；A06、A10、A11、A15、A17、A21、A25—A32 |

## 3. 实现职责与边界

| 模块 | 维护的产品规则 | 与页面的关系 |
| --- | --- | --- |
| 记录服务 | 最小保存条件、修订、类型、状态、数量、变化事件 | P03、P05、P06、P10、P14 |
| 位置服务 | 树层级、同名、路径、迁移和引用 | P04、P07—P09 |
| 媒体服务 | Picker 与分享资源接收、方向、压缩、候选、引用生命周期 | P03、P06、P09、P16、P17 |
| 检索服务 | 字段归一化、范围、稳定排序与索引更新 | P01、P02、P08、P14 |
| 草稿与入口协调 | 会话、继续任务、外部入口、重复动作标识 | P03、P06、P16、P18 |
| 日期服务 | 日期计算、当天一次、同日汇总、权限状态及系统任务关联 | P06、P12、P20、P21 |
| 数据管理 | 格式版本、快照、导出、恢复与系统备份适配 | P13 |
| 界面基础 | 设计令牌、组件、导航、可访问性与动效 | 全部页面 |

页面只表达当前任务和状态，通过统一服务执行正式变更。系统回调先进入对应能力适配，再转为可理解的页面状态。数据字段和状态枚举以 `09` 为依据，权限与导出格式以 `10` 为依据。

## 4. 性能与体验目标

以下均为开发目标。目标设备为当前连接的 HarmonyOS 7 手机，常规档位为 1000 条记录、100 个位置、每条平均 2 张图片；图片处理另记文件大小和像素。容量上限观察使用 `09` 的 10000 条档位，数据来源与数量写入验收。

| 任务 | 初始目标 | 测量起止与方法 |
| --- | --- | --- |
| 冷启动到首页可操作 | 95% 样本 ≤ 1.5 秒 | 点击图标到搜索/记下可响应，记录 20 次和环境 |
| 本地文本保存 | 95% 样本 ≤ 300ms | 点击保存到正式提交回执，记录 20 次 |
| 搜索结果 | 95% 样本 ≤ 500ms | 最后一次输入到结果稳定，包含 200ms 防抖，记录 20 次 |
| 详情打开 | 95% 样本 ≤ 500ms | 点击卡片到名称与位置可读，图片独立记录 |
| 一张选图处理 | 常见 1200 万像素图片目标 ≤ 1.5 秒 | Picker 返回到有效缩略图，记录 10 次及大小 |
| 滚动和过渡 | 60Hz 模式目标每帧 16.7ms 内完成主要绘制 | 通过真机性能工具记录帧时间；高刷新率按当前刷新周期单独评估 |

记录时间另按 `02` 的用户任务测量，包含人的理解和输入过程。识别耗时记录实际设备表现，等待到 8 秒出现可继续操作的说明。容量档位需要可核对的数据来源；样本条件齐备后填写对应结果。

## 5. 阶段完成标准

每个工作项包含实际页面、明确保存结果、输入保留、可执行的继续路径、可访问名称和对应手工验收证据。编译及静态检查服务于当前改动；运行验证在用户连接的手机上执行，步骤和结果写入文档。

交付记录分为设计就绪、已实现、已验证、待修正、待验证。已验证对应具体设备、应用版本、操作和证据。系统备份、卡片、识别模型、通知表现等依赖设备条件的项目按实际执行结果记录。

## 6. 发布准备

全部需求实现后核对名称、包名、图标、版本、隐私说明、系统权限声明、商店截图和应用介绍。应用介绍围绕“记住放哪，用好已有”“拍照或写个名字即可开始”“按位置整理、随时找回”组织。截图展示真实功能，隐私说明依据最终实际接入范围同步更新。

版本交付附需求覆盖表、真机验收记录、数据格式版本、已知待处理项及恢复说明。发布和上架按用户当轮授权执行。
