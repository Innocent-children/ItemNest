# 我的家当：产品文档与设计原型

版本：1.1 · 更新日期：2026-11-01。

“我的家当”帮助用户记住自己拥有什么、放在哪里，以及物品当前的状态。本套交付包括 16 份主体文档、一个交互原型和调研证据，供开发实现页面、业务规则、数据管理与 HarmonyOS 系统能力。

设计的核心是**让一次很小的记录投入形成可找回的线索，再让每次寻找和变化自然带动更新**。名称或照片即可保存；已有物品可以整组记录；连续整理复用位置；查找和移位直接连接后续维护。录入时填写到期日，或用生产日期和保质期算出日期，保存后在到期当天提醒一次。详细机制与判断依据见 [02-低负担记录核心机制](02-低负担记录核心机制.md)。

## 原型与实际证据

打开 [交互原型](Prototype/index.html)，按 [原型说明](Prototype/README.md) 体验。桌面显示设计说明与手机画面；手机显示完整的触控界面。顶部“空白开始”与“查看示例”切换两份独立演示数据，“场景”入口可直接查看到期日期输入、通知示意、扫码查同款、分享、卡片、备份、外观与读取提示。

原型覆盖记录、连续整理、搜索、详情、移位、位置管理、状态操作和设置等关键体验。系统接入通过有明确标记的界面场景表达；正式的数据合约与能力接入分别按 `09`、`10`、`08` 实现。

2026-11-01 已在连接手机浏览器中实际查看首页、详情、改位置、空白开始、仅名称保存、搜索、仅照片保存、连续记录、我的和深色主题。本轮追加保质期计算与保存、通知跳转、扫码同款复用、语音候选、快捷入口及提醒设置的检查。操作与截图对应表见 [原型实际检查记录](Prototype/README.md)。酷安参考截图与观察见 [调研文档](11-华为规范与酷安调研.md)。

## 建议阅读顺序

1. 阅读 `01`、`02`，理解用户为什么需要记录，以及每次使用获得什么。
2. 对照原型阅读 `03`、`04`、`05`，理解需求、路径和页面结果。
3. 用 `06`、`07` 落实视觉、组件与动效；用 `11` 核对设计来源。
4. 用 `09`、`10` 建立数据和业务合约，用 `08`、`15` 接入系统能力，按 `16` 准备账号和权限。
5. 按 `12` 开发，以 `13` 留存真机结果，规则调整同步 `14`。
