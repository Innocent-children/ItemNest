# 我的家当：产品与开发文档

版本：1.1 · 更新日期：2026-11-01。

“我的家当”帮助用户记住自己拥有什么、放在哪里，以及物品当前的状态。本套文档包括产品规格、设计规范、开发说明和真机操作记录，供开发实现页面、业务规则、数据管理与 HarmonyOS 系统能力。

设计的核心是**让一次很小的记录投入形成可找回的线索，再让每次寻找和变化自然带动更新**。名称或照片即可保存；已有物品可以整组记录；连续整理复用位置；查找和移位直接连接后续维护。录入时填写到期日，或用生产日期和保质期算出日期，保存后在到期当天提醒一次。详细机制与判断依据见 [02-低负担记录核心机制](02-低负担记录核心机制.md)。

## 建议阅读顺序

1. 阅读 `01`、`02`，理解用户为什么需要记录，以及每次使用获得什么。
2. 阅读 `03`、`04`、`05`，理解需求、路径和页面结果。
3. 用 `06`、`07` 落实视觉、组件与动效；用 `11` 核对设计来源。
4. 用 `09`、`10` 建立数据和业务合约，用 `08`、`15` 接入系统能力，按 `16` 准备账号和权限。
5. 按 `12` 开发，以 `13` 留存真机结果，规则调整同步 `14`。
