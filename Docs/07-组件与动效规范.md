# 组件与动效规范

版本：1.2 · 2026-11-07。组件编号 C01—C12，动效编号 D01—D09。

## 1. 动效为用户解释什么

动效承担三件事：说明操作已经被接收，说明内容去了哪里，说明用户现在处于哪一层。物品照片、位置和用户正在编辑的内容保持连续，用户可以在动作过程中继续掌控任务。

华为官方转场规范按页面层级和元素关系组织动画，并介绍共享元素、共享容器等连续表达方式；手势规范强调按下反馈、跟手和离手后的运动衔接。本产品据此选择动效目的与形式。[转场动效](https://developer.huawei.com/consumer/cn/doc/doccenter-ux-design/transition-animation-0000001750078488?docScope=all)、[手势动效](https://developer.huawei.com/consumer/cn/doc/doccenter-ux-design/gesture-animation-0000001797038213?docScope=all)

## 2. 组件定义

| 编号 | 组件 | 内容与状态 | 交互规则 |
| --- | --- | --- | --- |
| C01 | 搜索框 | 图标、提示、文本、清除；普通、聚焦、输入中 | 点击进入 P02；清除回到建议；键盘提交保持当前结果 |
| C02 | 导航与记下 | 三个目的地及一个独立操作；选中、按下、焦点 | 页签切换保留上下文；记下打开 P03 |
| C03 | 物品卡片 / 行 | 主图、名称、位置、类型与状态；加载、内容、选中 | 点击详情；长按进入批量；借出与整组标记始终可辨 |
| C04 | 位置行 | 名称、路径、子层数量、选择与进入按钮 | 选择位置和进入下一级分别具有明确触控区 |
| C05 | 条件标签 | 条件文字、当前状态、可移除标识 | 点击切换筛选；移除后立即更新结果与摘要 |
| C06 | 输入字段 | 标签、值、说明、校验反馈 | 约束提示贴近字段；错误定位到首个待处理字段 |
| C07 | 照片选择区 | 拍照、图库、缩略图、主图标记 | 处理中保持占位；预览、移除与设主图为独立操作 |
| C08 | 主要操作区 | 一项主动作、可选辅助动作、执行状态 | 键盘展开时贴近键盘上沿；执行状态保留按钮尺寸 |
| C09 | 半模态面板 | 把手、标题、内容、操作 | 遮罩、返回、下拉共同遵循当前草稿保存规则 |
| C10 | 回执与轻提示 | 简短结果、对象名称、可选下一步 | 保存回执可查看或继续；短提示默认 3 秒，朗读时给足完成时间 |

| C12 | 影响确认 | 对象、数量、目标或期限、确认按钮 | 按真实影响范围生成内容，主要按钮写出具体动作 |

本轮实现的公共组件位于 `entry/src/main/ets/components/Common.ets`：`ActionButton`（可带图标的胶囊按钮）、`MenuRow`（带图标、右侧取值与箭头的行；`plain` 模式用于分组卡片内，非首行上方显示内缩分隔线）、`GroupCard`（把相关入口收进同一张卡片）、`QuickAction`（图标在上、文字在下的快捷操作，C08 的详情页形态）、`StatTile`（数字加口径）、`Segmented`（二到三项分段选择，常规模式切换时过渡 180ms）、`StatusTag`（状态与到期标签）。

通用可访问性：每个操作具有可读名称；当前选中、执行中和禁用原因都可被朗读。开关的名称同时表达控制对象，例如“在桌面卡片展示常用物品”。

## 3. 动效清单

以下时间为本产品自定义动效的初始设计参数，属于设计目标。原生组件自带动效采用系统实现；同一属性的动画由一个实现主体控制。

| 编号 | 触发与目的 | 运动对象与初始方案 | 完成状态 / 中断规则 |
| --- | --- | --- | --- |
| D01 按下反馈 | 手指按下，确认命中 | 自定义按钮缩放 1 → 0.97，约 80ms；抬起约 160ms 回到 1 | 手指滑出转为取消态，控件回到原尺寸 |
| D02 页签切换 | 选择一级目的地 | 选中背景约 220ms 移动；内容做 160—220ms 的轻量交接 | 连续点击以最后目标为准，各页滚动状态保留 |
| D03 页面进入 | 打开详情、位置或编辑 | 原生导航左右转场；自定义演示为 260ms，位移由 24vp 收敛到 0 | 返回采用反向层级关系；系统返回手势跟随手指 |
| D04 面板展开 | 打开记录或选择器 | 原生半模态；自定义演示约 300ms 自底部进入，遮罩同步到 24% | 手势关闭完成草稿保存；取消后焦点回到入口 |
| D05 图片连续 | 从卡片进入图片或详情 | 同一照片容器在 280—340ms 内改变尺寸和圆角 | 图片尚在加载时保持占位；返回定位来源照片 |
| D06 保存结果 | 正式保存成功 | 按钮状态切换、勾选与回执约 180ms 进入 | 成功依赖实际保存；用户可立即查看或继续 |
| D07 列表变化 | 移位、筛选、归档 | 可见列表在约 200ms 内重排；受影响卡片轻量收拢 | 以稳定记录标识保持其余卡片，保留可见锚点 |
| D08 等待反馈 | 读图、识别、导出 | 系统进度组件，读图保持固定占位；长任务展示明确阶段 | 完成即交接结果；继续编辑与取消保持可用 |
| D09 状态切换 | 常用、数量或主题变化 | 图形与文字在 120—180ms 内切换，必要时轻触觉反馈 | 新状态清楚稳定，数据结果保持唯一 |

自定义过渡优先采用缓出曲线。有弹性需求时通过系统物理动效表达，初始响应时间约 0.35 秒、阻尼比约 0.86，最终参数按真机手感校准。

## 4. 手势和滚动

- 列表纵向滚动优先响应内容浏览；长按进入选择模式后，通过点击增加选择。
- 图片预览支持双指缩放，横向翻图作用于当前照片集合；系统边缘返回保留其系统优先级。
- 半模态内容可滚动时，先处理内容滚动；到达顶部后，下拉可交由系统面板处理关闭。
- 手势取消后回到本次动作开始前的业务状态；已经明确完成的保存结果保持生效。
- 搜索与表单的键盘出现过程由系统管理，页面跟随可用区域变化；主要操作随键盘位置移动。

## 5. 材质、光影与触觉

标题栏和底部页签采用 HDS 沉浸材质，面板、菜单与系统开关采用 HarmonyOS 7 对应的系统能力。材质等级跟随系统和设备。正文卡片用实色底提供稳定阅读；照片和用户内容在视觉上保持主体位置。

触觉只用于用户能够理解的完成节点，例如选择进入、保存成功和确认变化，并遵循系统触觉设置与设备能力。触觉关闭时，文字与视觉反馈完整表达同一结果。

## 6. 简洁动效

应用的“简洁”和系统的“减少动效”任一开启时，一级页签、导航和应用控制的展开、选中、双击放大直接切到目标状态。用户主动捏合或移动照片时，照片继续跟随手指。系统面板、日期选择器和键盘由系统管理。页面层级通过标题、返回和内容结构保持清楚。

## 7. 开发交接的逐项信息

每个页面标注需写出：对应 C 编号、触发方式、原生或自定义实现、受影响属性、开始状态、结束状态、业务提交时点、取消行为、朗读焦点和简洁动效表现。D 编号描述同类动效，页面中具体参数通过统一令牌维护。

D01—D09 的实际表现以原生真机验收为准，分别记录交互连续性、共享元素和系统返回跟手表现。

## 8. 真机验收重点

观察快速连续操作、面板下拉、键盘切换、列表移位和深浅色切换。每次检查记录手机系统、字体大小、实际刷新率、系统材质设置与应用版本。逐帧时长和曲线的判断依靠录屏或性能工具；布局和关键状态以现场观察文字记录留存。当前酷安调研的证据类型与适用结论见 `11`。

## 9. 本轮能力扩展的组件复用

P20 使用 C06 输入、C05 分段和 C08 保存区；切换填法采用 D09，日期结果原位更新，输入焦点保持在当前字段。P21 使用标准开关与 C10 真实结果反馈。P22 由 Scan Kit 管理扫码界面，返回结果采用 D03 进入列表。P23 使用 C09，准备和识别使用 D08，结果采用 D09。系统通知及桌面入口的实际动效交由平台。

## 10. 原生操作的动效与中断规则

| 操作 | 常规表现 | 连续操作与返回 |
| --- | --- | --- |
| 切换家当、位置和我的 | HdsTabs 执行 200ms 内容转场。图标与文字在转场开始时指向目标页签。 | 每页使用独立 Scroller。首页绘制后在不同空闲帧预加载位置和我的内容；切换完成只保存页签偏好。 |
| 进入子位置、查看拆分来源 | Navigation 按各栈项自己的位置或物品编号构建内容。 | 边缘返回过程中，上一页显示它自己的对象。批量模式先退出选择。 |
| 展开录入面板，切换日期或更多信息 | 系统面板出现后请求空白名称的焦点。表单内的展开和收起使用 180ms 过渡。 | 列表中段先滚动，回到顶部后继续下拉可关闭面板。编辑中从位置、照片按返回先回到表单。 |
| 从保存回执查看物品、从拆分进入新记录 | 原操作完成后，面板先关闭，再由原生导航打开目标详情。 | 业务写入成功才切换到回执。返回时恢复原来的页面。 |
| 详情、编辑和分享中查看照片 | 双击切换原图和 2 倍，双指以当前倍率和手势中心继续缩放，最高 4 倍。 | 全图时单指横滑翻页。放大后单指在本图范围内移动。恢复全图可再次翻页。详情预览返回后保留刚查看的照片。 |
| 搜索语音、语音填写名称或说明 | 系统半模态显示麦克风状态、识别文字和取消操作。 | 关闭开始时停止识别，原页面保留输入状态。编辑面板继续承载草稿。 |

手机上的操作、帧耗时口径和未覆盖条件见《19-原生应用真机验证记录》。API 26 的 `accessibility.isAnimationReduceEnabledSync` 与 `onAnimationReduceStateChange` 提供系统减少动效状态。页签和半模态的依据查阅于 2026-11-07。[华为页签切换与选中状态](https://developer.huawei.com/consumer/cn/doc/doccenter-dev-faq/faqs-arkui-451?docScope=all)、[华为半模态页面与嵌套滚动](https://developer.huawei.com/consumer/cn/doc/doccenter-capabilities/arkts-sheet-page)、[华为手势动效](https://developer.huawei.com/consumer/cn/doc/doccenter-ux-design/gesture-animation-0000001797038213)
