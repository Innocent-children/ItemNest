# 工程构建与安装

本轮工程采用 HarmonyOS Stage、ArkTS 与 ArkUI，包名 `com.imotong.itemnest`，版本 1.0.0。最低及目标 SDK 为 26.0.0。本机已使用 DevEco Studio 配置自动调试签名；签名私钥与口令只保留在本机配置，不纳入 Git。

## 从干净工作区打开

1. 将根目录 `build-profile.template.json5` 复制为 `build-profile.json5`。模板只包含 SDK、产品和模块配置，没有签名凭据。
2. 用 DevEco Studio 打开工程，在项目结构的签名配置中启用自动生成签名文件，选定本机已具备的调试材料，并将 default 产品关联到该签名配置。
3. 使用 API 26 SDK 构建。账号注册、认证、能力申请及发布签名由用户决定，清单见 `18-需用户处理的事项.md`。

本机命令如下，路径按实际安装位置调整：

```sh
env PATH=/Applications/DevEco-Studio.app/Contents/tools/node/bin:$PATH DEVECO_SDK_HOME=/Applications/DevEco-Studio.app/Contents/sdk /Applications/DevEco-Studio.app/Contents/tools/hvigor/bin/hvigorw --mode module -p product=default -p module=entry@default assembleHap --no-daemon
```

产物为 `entry/build/default/outputs/default/entry-default-signed.hap`。安装完成后再启动；不要在安装尚未结束时启动应用。

```sh
/Applications/DevEco-Studio.app/Contents/sdk/default/openharmony/toolchains/hdc install entry/build/default/outputs/default/entry-default-signed.hap
/Applications/DevEco-Studio.app/Contents/sdk/default/openharmony/toolchains/hdc shell aa start -b com.imotong.itemnest -a EntryAbility
```

## 工程入口

- `entry/src/main/ets/pages/Index.ets`：导航、家当、检索、位置、详情、状态操作和设置。
- `entry/src/main/ets/components/`：记录编辑、分享确认、语音候选、数据管理和公共界面组件。
- `entry/src/main/ets/data/Repository.ets`：关系型持久化、业务事务、修订、草稿和资源维护。
- `entry/src/main/ets/services/`：照片、文字识别、日历、备份文件、分享与卡片刷新。
- `entry/src/main/ets/extensions/`：桌面卡片和系统备份扩展。

设备日历状态与可重建缓存独立于完整备份。业务提交通过关系型事务写入；备份从业务快照生成，恢复先检查 ZIP 路径、清单摘要和业务引用，确认后一次替换业务数据。系统备份只传递专门生成的完整快照，恢复沿用文件校验路径。
