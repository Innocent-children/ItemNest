# 视觉设计规范

版本：1.1 · 2026-11-01。设计语言：**温和、清楚、随手可用**。

## 1. 用户应当感受到什么

“我的家当”呈现用户自己的生活物品。界面应让照片容易辨认、位置容易阅读、操作容易找到。暖白与深绿承接现有搬家人物图标的生活感，圆角和留白让记录显得轻松，系统材质把操作层与内容层区分开。

华为 UI Design Kit 提供符合 HarmonyOS Design System 的扩展组件和光影能力，本产品将其用于导航、页签与系统交互。HarmonyOS 7 的沉浸光感由系统根据设备能力和用户设置调整表现；本产品的内容层、操作层和状态反馈据此建立一致关系。[UI Design Kit](https://developer.huawei.com/consumer/cn/doc/doccenter-capabilities/ui-design-introduction)、[沉浸光感简介](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/arkts-immersive-light-sense-overview)

## 2. 视觉层级

| 层级 | 呈现 | 用途 |
| --- | --- | --- |
| 环境层 | 暖灰白 / 深绿色黑背景 | 让照片与卡片成为视觉主体 |
| 内容层 | 实色卡片、清楚的文字与缩略图 | 家当、位置、搜索结果和字段 |
| 操作层 | 系统材质、浮动导航、圆形主要操作 | 随时到达搜索、记录和页面目的地 |
| 聚焦层 | 系统半模态面板与明确标题 | 记录、选择位置、确认范围 |
| 反馈层 | 简短回执、状态标签、轻量提示 | 告诉用户结果和下一步 |

照片丰富时保持文字底色稳定。材质集中作用于可核实的官方支持区域，普通内容卡片采用实色背景，具体适配规则见 `08`。

## 4. 字体与字号

正文使用 HarmonyOS 系统字体，并跟随用户的系统字体选择。酷安的现场观察记录了手机的实际字体呈现，产品同样遵循系统字体设置。

| 语义 | 初始字号 / 行高 | 字重 | 应用 |
| --- | --- | --- | --- |
| 页面主标题 | 28sp / 36sp | Medium | 家当、位置、我的 |
| 二级页标题 | 20sp / 28sp | Medium | 详情、编辑、搜索 |
| 分组标题 | 18sp / 26sp | Medium | 最近记下、位置列表 |
| 物品名与正文 | 16sp / 24sp | Regular / Medium | 列表和表单 |
| 辅助信息 | 14sp / 22sp | Regular | 位置、状态、说明 |
| 次级标记 | 12sp / 18sp | Regular | 时间、页码 |

物品名在网格中最多显示两行，详情完整展示；位置路径优先完整换行。数字使用稳定的等宽数字特性，保证数量变化时布局安定。系统大字号下增加控件高度、减少列数，保留用户设定的字号。

## 5. 布局与空间

采用 4vp 基础间距，常用值为 4、8、12、16、20、24、32。手机页面左右边距 20vp；密集列表可采用 16vp。网格间距 12vp，卡片内部间距 12vp。

| 当前内容可用宽度 | 内容布局 |
| --- | --- |
| 小于 360vp，或大字下两列内容难以完整展示 | 单列列表 |
| 360—599vp | 家当两列网格，搜索单列 |
| 600—839vp | 内容按最小卡片宽度 168vp 自适应为 2—3 列，表单最大宽度 560vp |
| 840vp 及以上 | 导航侧置，列表与详情可分栏；单卡保持舒适阅读宽度 |

宽度来自当前窗口与安全区，设备类型只用于能力判断。横屏高度较小时，页面优先保持内容可滚动、主要操作可触达。

底部悬浮导航高度以 HDS 初始 56vp 为基准，三个目的地形成约 236vp 的导航区，右侧是 56vp 记录按钮，间隔 12vp。手机可用宽度不足时，整体缩小外侧留白，目的地仍具有至少 48vp 的触控区域。正文末尾的净空为操作区实际高度、底部安全区和额外 24vp 的总和。

## 6. 形状与图片

- 物品卡片圆角 20vp；照片容器圆角 16vp；输入框圆角 16vp；标签为胶囊形。
- 位置卡片圆角 20vp；全宽半模态面板顶部圆角以系统样式为准。
- 物品主图采用 4:3 容器，缩略图裁剪取中；用户在详情中可看到完整原比例照片。
- 单件卡片显示一张主图；整组卡片叠加“整组”标记，详情提供多图浏览。
- 图片为空时使用类别图形与轻底色，名称仍是主要识别信息。
- 图片读取中用相同尺寸占位，避免列表内容跳动。

## 7. 图标与品牌素材

应用身份使用项目已有的两版搬家人物图形：`AppScope/resources/base/media/foreground.png` 为女生版，`AppScope/resources/base/media/buddy_foreground.png` 为男生版。用户在“我的 → 应用图标”选择，默认采用女生版；应用内空状态与帮助页的人物随系统当前图标选择更新。界面展示预览时保留图形完整比例。

功能图标采用 HarmonyOS 系统 Symbol（`SymbolGlyph` 与 `$r('sys.symbol.*')`），名称以本机 API 26 SDK 的系统资源表为准。主要对应关系：搜索 `magnifyingglass`、扫码 `barcode_viewfinder`、记下 `plus`、位置 `mappin_and_rectangle`、改位置 `arrow_left_arrow_right`、找到了 `checkmark_circle`、借出 / 归还 `arrowshape_turn_up_right` / `arrowshape_turn_up_left`、编辑与草稿 `square_and_pencil`、日期 `calendar`、提醒 `bell`、常用 `star` / `star_fill`、归档 `archivebox`、回收站 `trash`、拍照 `camera`、相册 `picture`、语音 `mic`；底部导航为 `house`、`map`、`person`。分类图形：整组 `square_stack_3d`、数码 `headphones`、衣物 `shirt`、家居 `sofa_fill`、食品 `fork_knife`、工具 `wrench_and_screwdriver`、证件 `doc_text`。按钮始终有可读标签或可访问名称；快捷操作图标 24vp，列表与按钮内图标 18—20vp，行尾箭头 16vp。

人物图形用于首次使用、关于页和帮助说明，尺寸随信息密度调整。它与物品照片共同传达亲切感。

## 8. 明暗与可访问性

默认跟随系统明暗模式，用户也可选择固定浅色或深色。主题变化保留当前任务、输入和滚动位置。系统材质由系统决定效果级别；实色表单和文字使用对应语义色。

所有主要动作具有至少 48vp × 48vp 的触控区域。朗读顺序为标题、内容、字段、主要操作；图片提供“物品名称，第 X 张照片”语义，纯装饰图片作为装饰处理。

简洁动效保留状态与层级变化，缩短位移和缩放。键盘出现时，当前字段和保存按钮同时可见。视觉检查覆盖 360vp、390vp、600vp 及系统大字条件；当前手机验证记录见 `13`。

## 9. 原生界面适配

应用以 ArkUI、UI Design Kit 和系统组件实现布局与交互，适配采用 vp、sp 与系统安全区。所有具体数值在真机上结合系统字体、刷新率、材质等级和窗口尺寸复核。

## 10. 日期、语音与系统入口的视觉应用

P20 的两种日期填法复用现有分段控件与输入框，计算结果用主文字和浅绿色表面，作为表单中的一行自然出现。今天到期、临期与已过期均使用 warning 色配合明确文字；处理完成使用次级文字。通知示意采用系统通知的标题、应用标识和摘要层级，原生展示交给系统。P23 语音采用现有半模态和主要按钮，录音状态同时用文字表达；这些扩展继续沿用同一套色彩、间距和深浅色令牌。

## 11. 桌面卡片

P18 使用 surface 实色表面，跟随系统深浅色；外轮廓由桌面卡片宿主管理。内边距 14vp，标题行 24vp，主体间距 10vp。标题 15sp、操作文字 14sp，操作文字在空间不足时自适应至 11sp；名称 13sp、位置与日期 11sp。小卡两个操作纵向排列，保留完整名称，搜索采用 subtle 底色、记录采用 primary 底色。横向卡将摘要与 90vp 操作区分列，三条摘要等分可用高度。四款共用同一套间距、字级、颜色与线性图标。

SVG 直接提供浅色与深色资源，保留透明填充与描边；Image 不额外设置 fillColor，避免实际卡片渲染把线框填成实心。卡片无持续动画，保持桌面浏览安静。当前字体与设备外观验收见 Docs/19。
