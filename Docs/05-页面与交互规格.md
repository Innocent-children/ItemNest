# 页面与交互规格

版本：1.1 · 2026-11-01。页面编号沿用 `04`；字段范围与业务变化统一参照 `09`。

## 1. 全局约定

页面以用户当前任务组织。首屏始终能回答“我在哪、现在能做什么、刚才的操作得到什么结果”。标题、内容、主要操作从上到下排列；表单保存按钮位于键盘上方的固定操作区。

- 常规页面采用系统安全区。照片可向顶部延伸，文字与按钮保持在安全区内。
- 一级页面使用三目的地悬浮导航；“记下”按钮与导航同处底部操作区，保持独立操作语义。
- 每个列表状态均包含：首次读取、内容、内容为空、读取遇到问题。读取遇到问题时保留已显示内容并提供“重新读取”。
- 所有按钮有按下、焦点、禁用和执行中状态。执行中的保存按钮只对应当前一次动作。
- 弹层打开后，朗读焦点进入标题；关闭后返回触发控件。正文、控件和反馈按阅读顺序获得焦点。
- 长文本按内容扩展高度，主要动作完整显示；位置路径可以换行。字段限制提示靠近字段。

## 2. P01 家当

关联 F01、F03、F05、F07。首屏结构：应用标题与记录条数 → 搜索栏 → 近期日期卡 → 草稿条 → 筛选栏（含分类）→ 物品网格 → 底部导航与“记下”。搜索栏左侧为搜索图标，右侧为扫码图标，点击扫码图标直接进入 P22，点击其余区域进入 P02。

物品卡片上半部为 3:2 图片区：有照片时显示主图；没有照片时以浅绿底色显示分类图标（整组、数码、衣物、家居、食品、工具、证件），未选分类时显示名称首字。下半部为名称、位置和状态标签，文字区保持统一最小高度，同一行卡片顶部和底部对齐。状态标签只表达与“在手 1 件”不同的情况：借给谁、整组、数量大于 1、30 天内到期或已过期（7 天内用提醒色）。常用记录在图片右上角显示星标。

| 状态 | 呈现与操作 |
| --- | --- |
| 首次使用 | 搬家人物插图；“记住放哪，用好已有”；“先记一件你以后会找的东西”；主按钮“记下一件”，文字入口“看看示例” |
| 已有记录 | 显示单件与整组记录概况；默认按记录更新时间倒序；每卡片展示照片、名称、位置、状态 |
| 存在草稿 | 近期日期卡下方出现一条“继续刚才的记录：名称”，点击恢复最近编辑的草稿 |
| 有近期日期 | 存在 30 天内到期或已过期、尚未处理的日期时，搜索栏下方显示日期卡：有过期项时标题为“有日期需要处理”，否则为“快到期了”；列出最近 3 项及“明天到期”等相对说法，右上角显示总数，点击进入 P12。系统通知仍按到期当天 09:00 一次执行 |
| 筛选结果为空 | 保留筛选标签，文案“这里还没有对应记录”，操作“查看全部”“记下一件” |
| 示例视图 | 顶部持续显示“示例家当”，底部提供“开始记录自己的物品”；退出返回真实数据 |

筛选栏首层为“全部、常用、借出、整组”，分类通过筛选按钮展开。多个条件同时生效时显示条件摘要和清除入口。长按卡片进入 P10；点击卡片打开 P05。重新打开 P01 保留筛选和滚动位置。

## 3. P02 搜索

关联 F05。顶部为返回与搜索输入框；进入后焦点在输入框，系统键盘展开。搜索词为空时显示最近搜索最多 8 条、最近查看最多 6 条及“按位置找”。搜索历史在本机保存，用户可逐条清除或一次清空。

输入期间按 200ms 静默间隔更新结果；输入法组合文字提交后参与查询。搜索结果使用紧凑行：照片、名称、命中片段、完整位置和状态。借出条目显示对方称呼，整组条目显示类型。

匹配范围包括名称、别名、标签、说明和位置；名称、别名和位置另支持全拼与拼音首字母（如“huzhao”“hz”），繁体输入先转为简体，常见家用物品叫法（如“外套”与“羽绒服”）作为兜底匹配，排在直接命中之后。“在手与借出 / 归档”由可见的范围控件决定；回收站搜索位于 P14。清除搜索词返回建议状态。结果为空时显示“没有找到‘搜索词’”，主操作“记下‘搜索词’”，次操作“按位置找”。进入详情再返回，保留搜索词与定位行。

## 4. P03 记下

关联 F02、F03、F10。默认半模态面板，随着内容与键盘调整为可滚动的大面板。

1. 顶部标题“记下”，右上角关闭。
2. 名称输入框位于首位，提示“给它起个容易想起的名字”，右侧麦克风图标打开语音填写名称。
3. 名称下方为“记一件 / 记一组”分段选择。
4. 图片区以两个 84vp 方块提供“拍照”“相册”，加入的照片依次排在右侧，每张右上角有移除按钮，首张在多图时标注“主图”；达到 6 张后隐藏添加方块。
5. 位置、日期、更多信息三行收在同一张分组卡片中，各带图标；位置行显示“放在哪里”或当前完整路径，点击 P04；日期与更多信息在卡片内就地展开，收起时副标题概括已填内容。
5. 选择“记一组”时，名称下方直接显示“这组里面有什么”输入区及语音入口；“更多信息”展开分类、别名、标签，单件另含数量与说明。日期行独立展开。
7. 打开面板时名称输入框自动获得焦点并弹出键盘；键盘展开时面板整体让出空间，保存按钮始终可见；键盘“完成”键在名称或照片满足保存条件时直接保存。
6. 底部主按钮“保存”；存在照片时提供“提取照片文字”。

点击拍照进入系统相机选择器。相册返回后，缩略图先显示处理中，完成本地读入后成为有效内容。单条最多 6 张。选择主图通过预览中的“设为主图”完成，移除照片保留其他字段。

名称与有效照片均为空时，保存按钮禁用，旁边说明保存条件。保存成功后切换回执：“已记下”及物品、位置；操作“查看这件”“继续记下”。未选位置时，回执另提供“现在补上位置”：打开 P04，选择后直接更新刚保存的记录并刷新回执中的位置，随后“继续记下”沿用该位置。首次命名记录提供“试着找一下”，进入带有名称的搜索结果。从位置进入的连续会话额外显示“完成这次整理”。回执关闭后返回来源页面。

保存回执复述位置与到期说明（如“7 天后到期 · 当天 09:00 提醒”“已过期 10 天，不会再提醒”）。在回执中点“继续记下”后进入连续记录：之后每次保存不再显示回执，表单顶部显示“已记下「名称」· 这次第 N 条”，名称框重新获得焦点；右上角变为“完成这次整理”，关闭时提示“这次记下了 N 条”。

只有记录类型、带入的位置等上下文、没有任何填写内容时，关闭面板不生成草稿；应用启动时清理此类空草稿。从全局打开时，仅当最近一条草稿在 1 小时内编辑过，才询问“继续这条 / 另记一条”；更早的草稿通过首页草稿条和“我的 → 草稿”继续。草稿列表属于 P11 的子面板。

## 5. P04 选择位置

关联 F04。顶部标题“放在哪里”，下方位置搜索框。默认显示当前选择、最近使用最多 3 项与根位置。

- 位置行左侧名称与子位置数量，点击整行即选择；右侧“里面 ›”进入该位置的下一层，没有子位置的位置也可进入并新建子位置。进入下一层后顶部显示路径与“放在‘当前位置’”。最近使用只列出当前列表看不到的位置。详情中的“改位置”和批量移位置复用本面板，选择即完成。
- 顶部面包屑可回到任一上层；完整路径在选择确认区展示。
- “新建位置”打开 P09，保存后返回并选中新位置。
- “稍后补充位置”将位置设为空；位置批量迁移场景要求选择有效目标。
- 取消保留原值；确认后只更新来源表单的当前位置字段。

## 6. P05 物品详情

关联 F06、F08。页面自上而下：照片区（有照片时 4:3，多图显示指示点）→ 标题区 → 快捷操作 → 位置与日期卡片 → 说明卡片 → 更多操作 → 变化记录。

标题区：没有照片时左侧显示分类图标或首字方块；名称下方为状态标签（如“在手 · 1 件”“借给小林 · 1 件”）和最近日期标签；右侧星标切换常用，提示“已设为常用 / 已取消常用”。

快捷操作为一行四个图标按钮，覆盖找到实物后最常做的维护动作：在手且已有位置时依次为“找到了”“改位置”“借出”“编辑”；没有位置时第二项为“补位置”并以主色突出；借出时“借出”换为主色的“已归还”。归档和回收站中的记录不显示快捷操作，改为“恢复到家当”或“恢复记录 / 永久删除”。

位置与日期卡片：首行“放在这里”（借出时为“归还时放回”）显示完整路径，并在第二行显示“上次确认在这里：今天 晚上7:06”或确认引导；点击打开改位置。其下每个日期一行，显示相对说法与安排状态，点击进入 P12。拆分来源和缺失照片也在此卡片中列出。

更多操作为分组列表，默认展开、位于首屏下方：调整数量（右侧显示当前件数）、拆分数量（数量大于 1 时）、在这里再记一件、归档、移入回收站（危险色、需确认）。用户选择某项后进入对应的短表单，主按钮明确写出动作。变化记录为单独一行，右侧显示条数，点击就地展开。

“调整数量”提供当前数量与目标数量，输入 0 时展示“将归档为已用完”。拆分表单展示原数量、拆出数量、余量和两条记录的预览。

图片点击进入 P17。整组详情展示“整组记录”，说明中的物品名称可复制到搜索框；“在此位置记一件”带入位置并新建单件草稿。

## 7. P06 编辑物品

关联 F06、F08、F09。字段顺序：名称、照片、位置、记录类型、分类、标签、数量、备注、日期。

名称与照片满足同一保存条件。单件改为整组时展示“记录将以一组呈现”，数量退入变化记录；整组改为单件时要求明确填写数量。借出状态保持明确对象；数量修改影响整条借出记录。

日期区复用 P20：到期日期直接填写，或由生产日期和保质期计算；保修与归还各用日期选择器。到期提醒沿用全局设置，具体安排状态在日期旁显示。移除日期同步更新未来安排。底部“保存修改”更新正式记录；返回保留编辑草稿。

## 8. P07 位置与 P08 位置详情

关联 F04。P07 展示根位置卡片、当前位置覆盖的记录条数和代表图；尾部提供“新建位置”。空状态文案：“从最容易想到的地方开始，例如书房或玄关。”

P08 展示完整路径、当前名称和位置照片，随后是子位置和当前范围记录。范围选择“这里 / 包含子位置”，默认包含子位置，摘要写明口径。主操作“在这里记下”。

右上角“管理位置”提供改名、换父位置、添加照片和移除位置。父位置选择器展示有效候选，确认页显示子位置和记录的影响数量。移除有内容的位置时，先选择安置位置再确认。

## 9. P09 新建或编辑位置

名称必填，1—30 个 Unicode 字符；父位置可选；照片一张、备注最多 500 字。当前处于第 4 层时，入口引导用户选择上层父位置。

同级同名时，在名称下提示“这里已有这个位置”，提供“使用已有位置”和返回修改。移动导致层数超限时，展示调整后的最大层数及可选上层。保存后回到调用页面，保留已选的新位置。

## 10. P10 批量整理

关联 F07。顶部显示已选数量与“完成”，每条记录有明显勾选状态。底部为“移位置”和“移入回收站”。“全选”作用于当前筛选得到的完整记录集合，确认前显示实际总数。

移位置确认页同时展示目标路径和选中记录摘要；移入回收站确认页说明保留期限。保存期间保持选中集合，成功后退出选择模式；处理遇到问题时展示整体重试操作。

## 11. P11 我的

关联 F16。顶部为“我的”标题和一张概况卡片，并列三个数字：单件记录（条）、整组记录（组）、在手单件（件）。入口分三组卡片，每行带图标：常用、草稿、提醒；归档与回收站、数据管理；外观与隐私、帮助与关于。常用和草稿在右侧显示数量。

每个入口包含名称与一条有用摘要，例如“草稿 2 条”“最近完整备份：11 月 1 日”。资料为空时使用“可以制作一份完整备份”等行动文案。常用入口复用 P01 筛选结果；草稿列表提供继续、删除草稿及时间。

## 12. P12 提醒

关联 F09。分段为“待关注 / 已处理”。待关注按已过期、今天到期、未来日期分组，组内日期升序。每条显示名称、日期类型、实际日期和提醒安排状态，主操作“查看物品”，辅助操作“处理完成”“修改日期”。待补生产日期的记录在末尾显示“补上生产日期可计算到期日”。

顶部“到期提醒”行显示已开启或开启入口，进入 P21。说明为“到期当天上午 9:00 提醒，同一天合成一条”。当前只能应用内关注时准确显示“日期已保存”，已登记时显示具体提醒日期；过去时刻显示“在应用内关注”。日期的提醒时间统一为当天。

## 13. P13 数据管理

关联 F12。顺序为数据位置说明、完整备份、导出清单、从备份恢复、系统备份与换机说明。

点击完整备份，显示记录和照片数量、预计文件体积，用户选择保存位置，完成后显示实际文件名、时间与体积。写入中的页面显示进度阶段与取消入口；取消保留自己的家当。

恢复分为“选择文件 → 核对预览 → 选择方式 → 保存 → 结果”。预览列出各类记录数量和冲突数量；合并为默认方式，替换须明确勾选影响范围并确认。结果显示新增、更新、保留、照片缺失及日历待重建数量。详细文件格式见 `10`。

## 14. P14 归档与回收站

关联 F13。顶部两个页签“归档”“回收站”，各自可搜索。归档显示原因和时间；回收站显示剩余保留天数。

归档详情提供“恢复到家当”；回收站详情提供“恢复记录”“永久删除”。永久删除弹窗写出名称和影响的照片数量，主按钮为明确的“永久删除”。批量永久删除逐项计入确认范围。

位置已移除时，恢复预览显示原路径，用户可选择新位置或稍后补充。恢复成功后提供“查看记录”。

## 15. P15 外观与隐私

关联 F14、F15。包含主题、跟随系统字号说明、动效表现、桌面卡片内容、到期提醒、外部提醒详情、数据处理说明和系统权限入口。

主题使用“跟随系统 / 浅色 / 深色”分段选择，切换即时预览；开关统一使用应用主色。动效设置为“跟随系统 / 简洁”，简洁保留必要状态变化并缩短位移。卡片详情开关默认关闭，用户开启后选择最多 3 条常用记录；关闭后及时刷新已添加卡片。

数据说明清楚区分应用本地记录、系统日历、系统备份和用户导出的文件，文字见 `10`。

## 16. P16 接收图片

关联 F11。标题“把照片记进家当”，显示实际接收到的有效图片数。每张缩略图可预览或移除；记录方式为“每张记一件 / 合成一组”，位置可统一指定。

每张记一件时提供逐项名称，默认使用照片显示名；合成一组时提供一个组名和说明。最终按钮显示“保存 3 条记录”或“保存这组”。保存后展示结果列表与“回到来源应用”。

读取个别图片遇到问题时对应缩略图显示“重新选择”，有效图片继续保留；保存按钮清楚写出将保存的有效数量。所有外部输入在当前导入会话中呈现。

## 17. P17 图片预览与文字候选

关联 F10。全屏查看支持左右切换、双击放大和双指缩放。顶部展示张数，底部操作为“设为主图”“提取文字”。主图切换更新当前表单或经过明确确认后的记录。

文字候选面板保留照片缩略图和识别文本来源，提供“填入名称”“补充到备注”“选择日期”。用户先选文本再选择用途，日期包含完整年月日且真实存在时提供日期填入选项。

识别进行中可收起面板并继续编辑；超时或能力待就绪时提供重新尝试、输入名称和保留照片。结果按草稿标识与修订号进入候选区。

## 18. P18 桌面卡片

关联 F11。首版提供 2×2 与 2×4 两种规格。

- 2×2：应用名、简短提示、“找东西”“记一件”。
- 2×4：默认同样展示通用入口；用户开启摘要后展示最多 3 条常用记录的名称和位置。
- 点击通用入口进入 P02 或 P03；点击摘要进入 P05。2×4 可选择日期摘要模式，最多显示三条及更新时间，点击进入 P12。
- 图标长按显示“记一件、找东西、看临期、扫一扫”，分别打开 P03、P02、P12、P22。
- 卡片数据与应用更新后的正式记录同步；关闭摘要后恢复通用入口。

## 19. P19 帮助与关于

提供四段短说明：怎样先记下一件、怎样用整组记录、怎样确认位置、怎样长期保存数据。每段有相关操作入口。关于页展示“我的家当”、应用版本、隐私说明和本地诊断信息导出入口；诊断导出前可查看将包含的环境字段。

## 20. 全局可恢复状态

| 触发情形 | 页面如何帮助用户继续 |
| --- | --- |
| 相机或图库返回取消 | 回到原草稿，保留已有照片和文字 |
| 编辑中切换应用 | 当前内容进入草稿；回来继续当前任务 |
| 保存期间返回 | 展示当前保存状态，完成后按结果返回；一次动作对应一次提交 |
| 重复点击外部入口 | 已打开的同一记录保持最新状态；独立导入内容进入独立会话 |
| 记录刚被归档或回收 | 详情显示最新状态及相应恢复操作 |
| 系统日历权限变化 | 应用内日期保持可见，日历行显示当前接入状态与操作 |
| 可用空间不足 | 草稿保留可读内容，提示“释放一些空间后继续保存”及重新选择照片入口 |
| 字体放大或窗口缩小 | 内容改为单列，标签换行，底部操作完整显示 |

## 21. P20 到期日期输入区

关联 F09，内嵌在 P03、P06 的“更多信息”，各分类使用同一组件。标题“到期日期”，注明选填；两种填法为“直接填日期 / 按保质期计算”。直接模式显示日期选择器；保质期模式显示生产日期、整数期限及天/月/年单位。结果行即时显示“到期日期：2027-05-01”。已开启提醒时，辅助文字为“到期当天上午 9:00 提醒”；首次使用时为“开启提醒后，到期当天上午 9:00 提醒”，保存回执提供开启入口。

填写生产日期与期限即可得到结果，与整条物品共用保存按钮。生产日期为空时显示补充提示，已填期限随草稿和物品保存。数字超出范围、日期越界时在字段旁解释并保留输入。用户移除日期后，结果行回到选填提示。OCR 日期候选可以填入直接日期或用户明确选择的生产日期。

## 22. P21 到期提醒

关联 F09、F15。主开关“到期提醒”，说明“到期当天上午 9:00 提醒，同一天合成一条”。首次开启时，根据本机可用承载方式申请通知或日历授权；日历路径明确说明“将到期日期写入系统日历，用于提醒”。授权成功后安排有效未来日期，显示真实结果。

其余内容为“外部提醒显示物品名称”开关，默认关闭，以及需要处理的安排结果。正常状态只显示“已开启”；有待安排日期时显示具体条数与解决入口。系统容量、开发者权益和 API 名称由开发记录维护，界面使用用户能采取的操作。

原型的通知示意在审阅工具栏中打开，展示通知卡片及点击进入 P12 的关系；卡片显著标记“系统通知示意”。

## 23. P22 扫码查同款

关联 F17。入口位于搜索页和图标快捷方式；调用系统默认扫码界面。扫码成功后展示码值和本地匹配结果，结果显示各条的数量、位置、日期及状态。用户可查看已有记录，或从一条记录选择“再记同款”。首次码值显示“把这件记下来”，带条码进入 P03。

取消返回搜索或来源表单。支持的条码类型及长度以 `09` 为准。原型提供明确标记的模拟结果；正式页面使用 Scan Kit 返回的实际码值。

## 24. P23 语音填写

关联 F18。标题点明“说出名称 / 说出说明 / 说出搜索词”，正文依次展示准备、录音、识别结果和可编辑候选。主操作按状态为“开始说”“说完了”“采用文字”，辅助操作“取消”“重新说”。录音最长 30 秒，停止后保留候选供确认。

采用后返回原字段；名称和搜索词替换当前值，说明换行追加。权限、模型或资源条件需要处理时显示继续输入和重试。原型以“语音候选示例”表达交互；真机录音状态与系统指示由 H13 接入。
